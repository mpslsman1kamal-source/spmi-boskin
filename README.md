# SPMI BOSKIN 2026 — Frontend

Aplikasi web SPMI (Sistem Penjaminan Mutu Internal) berbasis Rapor Pendidikan.
Frontend statis (HTML/CSS/JS murni) + backend Google Apps Script (REST API).

- Konfigurasi: **hanya** `js/config.js` (isi `API_URL`).
- Panduan lengkap: **PANDUAN-INSTALASI.md**
- Keputusan desain & sinkronisasi dengan wireframe: **DESIGN-SYNC.md**
- Deploy: folder ini (yang berisi `index.html`) di-`git init` lalu `git push` ke GitHub Pages.
